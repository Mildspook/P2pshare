# P2Pshare

P2Pshare is a lightweight file-sharing application that lets you quickly share files and folders over your local network or across the internet.

## Features

* 📁 Simple file and folder sharing
* 🌐 Works on both local and external networks
* 🖥️ Easy-to-use Windows executable
* ⚡ Legacy Python version available for headless servers and terminal use

## Sharing Outside Your Local Network

To allow connections from outside your local network, **UPnP must be enabled on your router** so P2Pshare can automatically configure port forwarding.

## Downloads

### Windows (.exe)

The Windows executable is designed to be as simple as possible—just run it and follow the on-screen interface.

### Legacy Python Version

The original Python version requires **Python 3**.

It can be run entirely from the terminal without the GUI, making it suitable for headless systems or servers. By default, it shares the folder that the program is located in.
